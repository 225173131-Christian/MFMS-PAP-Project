I was responsible for displaying reports from the different parts of the Municipal Financial Management System the Project for Programming in pratise.

  The Reports Consists of five functions:
employeeReport
The employeeReport() function displays the employee report Such as the total number of employees, average salary, lowest and highest salary.

budgetReport
The budgetReport() function displays the Budget Report this would generate a report on the budget information

supplierReport
The supplierReport() function displays the Supplier Report, this would display the registered suppliers on the system stored.

assetReport

The assetReport() function displays the Asset Report, this would provide two parameters:
Asset assets[]
int assetCount
The assetCount keeps track of the number of assets being passed to the report.
The assets keep track of the assets names

displayReportsMenu
The displayReportsMenu() function displays the Reports Menu, the function provides the menu which contains:
1. Employee Report 
2. Budget Report
3. Supplier Report 
4. Asset Report 
5. Return to Main Menu

eports.h
reports.h is the header file for the Reports Module, it contains the function declarations for the Reports which would be accessed and used by the main.c program file
