## What the program does

| Module :  What it does |

| **Main Menu**           : Shows the options and sends the user to the right module. Invalid choices are handled. 
| **Employee Search**     : Finds an employee using their ID or name. 
| **Supplier Management** : Adds suppliers (name, email, phone, town), displays them and searches for a supplier by name. 
| **Salary Calculation**  : Adds basic salary, housing and transport allowances to give the gross salary. 
| **VAT Calculation**     : Works out the VAT on an amount. 
| **Budget Calculation**  : Subtracts expenses from revenue and shows a surplus, deficit or balanced budget.
